# 07 — C# ASP.NET Core MVC : projet d'intégration

**Session :** Automne 2026 (en cours) · Projet d'équipe de 5

> 🔒 Le code de ce projet n'est **pas public** pour le moment. Il est développé dans le dépôt GitHub du cégep. Cette page le présente seulement.

## Le projet

Un **logiciel interne** pour une fondation qui offre des services bénévoles aux personnes aînées : réservations, transports, horaires des chauffeurs et de leurs indisponibilités, services bénévoles.

| | |
|---|---|
| **Technologies** | C#, **ASP.NET Core MVC** (.NET 10), Entity Framework Core, SQL Server, ASP.NET Identity |
| **Organisation** | Équipe de 5, travail en *sprints*, branches Git, *pull requests* et revues de code |
| **Ce que je pratique** | Contrôleurs et vues Razor, gestion des rôles (administrateur, réceptionniste, chauffeur), migrations, génération de données de test |

Ce projet est la suite logique de mon parcours. Il réunit le C#, les bases de données et le web dans une vraie application d'équipe.
