# 08 — Vue.js

**Session :** Automne 2025 · Projet d'équipe de 3 (avec Charles-Antoine Ertug et Mamadou Ba)

Ce projet a **son propre dépôt** :

## 👉 [exploration-spatiale-vue](https://github.com/anicetmiz/exploration-spatiale-vue)

Une application web d'exploration spatiale : systèmes solaires, planètes, vaisseaux et ressources.

| | |
|---|---|
| **Technologies** | Vue.js 3 (Composition API), Vue Router, Bootstrap 5, Vite |
| **Ce qu'il montre** | Composants avec `props` et `emits`, `ref` et `computed`, routes dynamiques avec paramètres et *query strings*, filtres et tri des données |

Son README est écrit pour un débutant : il explique chaque notion de Vue.js et comment refaire le projet en 10 étapes.
