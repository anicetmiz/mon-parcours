# 05 — C# WPF avec le patron MVVM

**Session :** Automne 2025 · Projet individuel

Ce projet a **son propre dépôt** :

## 👉 [gestion-centre-sportif-wpf](https://github.com/anicetmiz/gestion-centre-sportif-wpf)

Une application de bureau WPF pour gérer un **centre sportif** : ses cours, ses membres et leurs inscriptions.

| | |
|---|---|
| **Technologies** | C#, .NET 8, WPF, XAML, **MVVM**, Entity Framework Core, SQL Server, LINQ |
| **Ce qu'il montre** | Binding de données, commandes (`ICommand` / `RelayCommand`), validation avec `IDataErrorInfo`, communication entre ViewModels par événements, migrations Entity Framework |

Son README explique en détail le patron MVVM, le modèle de données, les règles d'affaires et comment refaire le projet étape par étape.
