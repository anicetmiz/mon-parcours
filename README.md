# 📈 Mon parcours en programmation

**Anicet Mizumbi** · Étudiant en dernière année de Techniques de l'informatique au **Cégep de Granby** · [github.com/anicetmiz](https://github.com/anicetmiz)

Ce dépôt montre **ma progression**, de mes premières pages en HTML et CSS jusqu'aux applications complètes en C#, en Vue.js et en Kotlin. Les projets sont classés **dans l'ordre où je les ai appris**. Chaque projet a son propre README, qui explique ce qu'il fait, comment le lancer et ce que j'y ai appris.

> 🤖 **Note sur l'utilisation de l'IA :** les projets de ce dépôt ont été réalisés par moi, à différents moments de mon parcours au Cégep de Granby (de l'automne 2024 à aujourd'hui). J'ai utilisé **Claude** (IA d'Anthropic) pour m'aider à **organiser** ce dépôt, rédiger les README et nettoyer les fichiers. Le code des projets est le mien (ou celui de mon équipe, quand c'est indiqué), avec quelques corrections de bugs signalées dans les README.

```
Automne 2024   Structurer et styliser une page ......... HTML, CSS, Bootstrap
     │
Hiver 2025     Penser en objets ......................... Java (POO)
     │         Rendre une page interactive .............. JavaScript
     │         Interroger et concevoir une base ......... SQL
     │
Automne 2025   Relier le code à une base de données ..... C# + Entity Framework
     │         Structurer une application de bureau ..... WPF + MVVM
     │         Créer un serveur web ..................... API REST

     │
Hiver 2026     Développer pour mobile ................... Kotlin + Compose
     │
Automne 2026   Livrer une vraie application en équipe ... ASP.NET Core MVC
```
